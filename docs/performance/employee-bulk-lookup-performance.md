# 직원 조회 성능 개선

## 개선 배경

기존 방식은 직원을 한 명씩 조회해 10,000건 동기화 시 직원 조회가 10,000회 발생했습니다.

반복 동기화의 조회 비용을 줄이기 위해 사번을 묶음으로 조회하고, 그 결과를 기준으로 직원을 비교하도록 변경했습니다.

## 개선 결과

| 처리 데이터 | 직원 조회 | 처리 시간 |
|---|---|---|
| 10,000건 변경 없음 | 개별 10,000회 → 일괄 10회 | 27.17초 → 18.33초 |
| 1,000건 변경 + 9,000건 변경 없음 | 개별 10,000회 → 일괄 10회 + 개별 1,000회 | 29.77초 → 21.99초 |

- 10,000건 변경 없음: 처리 시간 32.53% 단축
- 1,000건 변경 + 9,000건 변경 없음: 처리 시간 26.14% 단축

## 측정 기준

동일한 Testcontainers 환경에서 반복 측정한 중앙값입니다. 동일한 조건에서 조회 방식의 차이를 비교했으며, 수치는 실제 운영 처리 시간을 보장하지 않습니다.
